## How to read v3 in German if you don't speak German

The German v3 documents use clear technical language. Two practical paths:

1. **Browser auto-translation** (Chrome / Edge / Firefox with extension) handles the documents acceptably for first reading. Mathematical formulas, code blocks, and equations are not translated — they stay in their original form.

2. **Targeted reading via the prologue:** start with `de/docs/v3_konsolidierung/RFT_v3_000_Prolog_Einsteiger.md` (when merged) — that is a 6-page entry document specifically written for solid-state physicists. It introduces the key concepts and terminology and serves as a roadmap.

3. **Direct contact:** for substantive scientific exchange, please reach out at `rft.projekt@posteo.de`. Franz Zollner is happy to discuss specifics with researchers in related fields.

---

## Why no full English version yet?

Translating 26 technical physics documents at quality level requires considerable time. The author and AI collaborators (Claude Code as "Denker", Claude as "Sokrates") are translating in stages, prioritising the entry-point documents.

For comparison: the predecessor English series under `foundations/` was created over months. v3 represents a significant consolidation and re-formulation of the theory; full English translation is in progress but not yet complete.
